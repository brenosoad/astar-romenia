# astar-romenia

Busca A* de Arad até Bucareste, do capítulo 3 do Russell & Norvig.
Trabalho de Inteligência Artificial I (IIA-008).

Aluno: Breno Soad

## Como rodar

    python a_estrela.py

## Resultado

Arad -> Sibiu -> Rimnicu Vilcea -> Pitesti -> Bucharest: 418 km em 4 passos,
igual à figura 3.24 do livro.

## Arquivos

- mapa.py: mapa da Romênia e heurística
- fase1_explorar.py a fase5_busca.py: etapas do desenvolvimento
- a_estrela.py: versão final
